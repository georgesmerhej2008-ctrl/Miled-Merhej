# Miled Merhej — النقل والونش في لبنان

## فتح الموقع على الكمبيوتر

فك ضغط الحزمة، ثم افتح **index.html** بالمتصفح. كل الصور والتنسيق والوظائف
مضمّنة في هذا الملف. لا تحتاج إلى تثبيت برامج أو تشغيل خادم.
تحتاج إلى الإنترنت لاستخدام WhatsApp. اضغط على أي صورة لتكبيرها داخل الصفحة.

## نشر الموقع على GitHub Pages

1. افتح https://github.com/new وأنشئ مستودعًا باسم **miled-merhej-website**.
   اختر **Public**، وفعّل **Add README**، ثم اضغط **Create repository**.
2. اختر **Add file → Upload files** وارفع **index.html** إلى الجذر مباشرة،
   ثم اضغط **Commit changes**. يمكنك رفع README.md و.nojekyll أيضًا.
3. افتح **Settings → Pages**. ضمن **Source** اختر **Deploy from a branch**،
   ثم اختر **main** و **/(root)**، واضغط **Save**.
4. قد يستغرق النشر حتى 10 دقائق. يظهر رابط الموقع في صفحة Pages بجانب
   **Visit site**. يمكنك مشاركة ذلك الرابط مع العملاء.

ارفع ملف index.html المستخرج؛ لا ترفع ملف ZIP نفسه ولا تضع الصفحة داخل مجلد إضافي.

## تعديل الموقع لاحقًا

يمكن تعديل النصوص داخل index.html باستخدام محرر نصوص وحفظه بترميز UTF-8،
ثم رفع الملف المحدّث إلى GitHub. الصور مضمّنة بصيغة Base64، فلا تحذف تلك
البيانات. تُحدَّث الصفحة المنشورة بعد رفع التعديل إلى الفرع main.
